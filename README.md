# Paz em Oração

Plataforma web de oração católica e apoio à saúde mental (pt-BR). Sem dependências: HTML, CSS e JavaScript puro.

## Recursos
- **Reflexão diária** com versículo e convite à prática
- **Check-in de humor** que sugere oração e cuidado adequados
- **Orações** tradicionais (Pai Nosso, Ave Maria, Serenidade, São Francisco, antes de dormir, entrega da ansiedade…)
- **Respiração guiada** (4-4-6) para acompanhar a oração
- **Diário** de gratidão/emoções, salvo só no aparelho (localStorage)
- **Ajuda imediata**: CVV 188, SAMU 192, Bombeiros 193, CAPS

## Executar
```
python3 -m http.server 8000   # e abra http://localhost:8000
```
Conteúdo editável em `src/data.js`.

> Não substitui atendimento psicológico, psiquiátrico ou médico.
